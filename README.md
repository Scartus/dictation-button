# Dictation Button v2 (import in progress)

This repository has the Android Gradle build configuration and the GitHub Actions APK workflow. **It does not yet contain the complete hardened v2 Kotlin source, so the workflow cannot produce a working APK yet.**

The full source currently exists as the archived project `dictation-button-v2-hardened.zip` attached in the originating ChatGPT conversation. It is not yet mirrored to GitHub.

Do not install or distribute a purported v2 APK until a successful Android build and device test have been completed. No OpenAI API keys or login credentials belong in this public repository.
